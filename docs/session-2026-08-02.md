## Post-sprint defect fixes (audited)

1. **`@functools.lru_cache(maxsize=2)` on `load_config`** — cached the *returned mutable dict*; run-1 in-place mutations (e.g. `--duration 30`) leaked into run 2 in-process. Fix: **dropped the cache** (audio_proxy already caches at its own layer; shared mutable dict across TUI/FastAPI/pipeline threads was the hazard). Regression test `test_load_config_returns_fresh_dict_per_call`.
2. **Supertonic temp file leak** (`audio_proxy.py` one-shot fallback) — `supertonic_input_*.txt` never unlinked. Fix: `finally` + `contextlib.suppress(OSError)` + `temp_file.unlink()`, matching the IndicF5 pattern (audio_proxy.py:173-175). Covers `TimeoutExpired` path.
3. **`_input` bridge in `consultation.py`** — sys.modules magic reading the facade namespace was needed only because 8 tests patched `agents.director_agent.input` (vestigial monolith-era target). Fix: migrated those 8 sites to `patch("builtins.input")` (same style as the other 11) and deleted the bridge.
