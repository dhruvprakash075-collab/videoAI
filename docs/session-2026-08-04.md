  (`plan_page_rects` count param + dataset filter); only the chunking was
  fixed at 5 (`compose_panel_pages` `range(0, len, 5)`) and `_panel_sizes`

  Stored order is scrape order (roboflow_NNN), not curated.
- Added `plan_page_counts(n_images, layout_file, fallback_layout_file,
  default_panels=5)` in `video/image_gen/panel_compositor.py` — walks the
  dataset in order (each page takes the next layout's panel count, cycling;
  final page = first count ≤ remaining, else the remainder via the fixed

  `image_gen._panel_sizes` mirrors it page by page.
