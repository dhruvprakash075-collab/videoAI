- **Dead chunk hints now consumed**: `b_roll_hint`/`key_event` were paid for by the by_llm splitter but never reached images. `_build_segment_state` merges them onto a COPY of the plan (never the shared outline dict — retries/other segments must not see the mutation) (:970-979); `enrich_prompts` appends `b_roll_hint` to the camera move (utils/scene_director.py:132-138).

- **Legacy CLI `--file` garbage-decode**: core/pipeline_cli.py read raw UTF-8 (a .pdf/.docx fed there decoded as garbage silently). Delegated to `load_source` (extension validation + PDF/DOCX + oversize check).

Now computes `real_mp4s`, logs ERROR + `assembly_missing_segments` degradation when segments are missing, and reports the honest count (core/post_production.py).
